# اعتبارسنجی اصلاح WebRTC — ۲۰۲۶-۱۱-۲۶

مبنا: کامیت `a3c01c0` (نسخهٔ ۱۹). دیتابیس، migrationهای منتشرشده، متن‌های مدادی،
آپلودها، مسیرهای پرداخت و پیامک تغییر نکرده‌اند. پورت وب ۳۹۰۰ و volumeها ثابت‌اند.

## تغییرات

- تنظیم ICE در زمان اجرا، فقط برای عضو مجاز کلاس؛ shared secret فقط سمت سرور.
- اعتبارنامهٔ موقت Coturn با HMAC و انقضا، پاسخ private/no-store و تازه‌سازی پیش از انقضا.
- صف محدود ICE قبل از offer/answer؛ شناسهٔ مستقل مذاکره و بازنشسته‌کردن نسل‌های قبلی.
- بستن peer و تایمرهای قدیمی، کنترل عملیات async پس از خروج، قطع/وصل و لغو مجوز رسانه.
- تشخیص دریافت رسانه با آمار inbound RTP: فریم decode‌شدهٔ ویدئو یا بایت دریافتی صوت.
- timeout سی‌ثانیه‌ای، پیام خطای قابل مشاهده و تلاش دوباره در نمای عادی و افقی موبایل.
- متادیتای نقش ناشر از سرویس احرازشده برای انتخاب استاد در نمای اصلی.
- راه‌اندازی اختیاری Coturn، جدا از Compose اصلی؛ ایجاد کلید تصادفی روی VPS، منع رله به
  شبکه‌های خصوصی، بررسی تداخل پورت و خارج‌کردن کانفیگ خصوصی از گیت/بافت Docker.

## آزمون‌های قابل تکرار

```bash
bun install --frozen-lockfile
bun test tests/stream-peer.test.ts tests/stream-ice.test.ts
bun test tests/stream-access.test.ts
bun run test:security
bun run typecheck
bun run build
cd mini-services/stream-service && bun install --frozen-lockfile && bun run typecheck
```

۱۹ تست جدید صف ICE، دیررسیدن SDP، بستن peer، خطاهای candidate، محدودیت/انقضای صف،
تشخیص فریم/صدا، HMAC/انقضای TURN و کنترل دسترسی کلاس پاس شدند.
۱۱ تست قبلی ورود/دومرحله‌ای و سازگاری وابستگی‌ها نیز پاس شدند.
فایل‌های Compose با parser YAML و اسکریپت setup با `bash -n` بررسی شدند.

## آزمون مرورگر و مرز نتیجه

خود هوک قدیم و جدید با React و Chromium headless و دوربین مصنوعی اجرا شدند؛
سیگنالینگ و پاسخ مجاز API در این آزمون کنترل‌شده شبیه‌سازی شدند. offer/answer
مبادله و تصویر محلی ۶۴۰ پیکسلی شد. در این محیط برای هر دو نسخه ICE در وضعیت
`new` ماند و هیچ فریم رسانه‌ای به دانشجو نرسید؛ بنابراین انتقال واقعی و موفق
بین دو مرورگر در این محیط **تأیید نشده است**.

تفاوت قابل مشاهده: کد قبلی با ترک‌های muted و صفر فریم، وضعیت را live اعلام
می‌کرد؛ کد جدید connecting می‌ماند و پس از timeout به error با پیام فارسی
تغییر کرد. تغییر کیفیت و retry مذاکرهٔ تازه ساختند و خطای JavaScript مشاهده نشد.
آزمون قطعی پخش با TURN واقعی، دو شبکهٔ مستقل و افزایش `framesDecoded` باید روی
VPS طبق README انجام شود. اجرای Docker/Coturn، فایروال ارائه‌دهنده و مسیر TURN/TLS
در این محیط آزموده نشده‌اند. فقط نصب کد، بدون فعال‌کردن TURN، تضمین اتصال در
شبکه‌هایی که اتصال مستقیم را مسدود می‌کنند نیست.
